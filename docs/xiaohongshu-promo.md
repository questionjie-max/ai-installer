🙋‍♂️ 朋友们，最近AI编程工具真的火到不行
Claude Code、Cursor、Codex、DeepSeek TUI… 每个都想试试对吧？

但问题来了 👇
❌ 装Node.js还要配环境变量
❌ npm官方源慢到怀疑人生
❌ 装一个工具要敲一长串命令
❌ 装完还要自己配PATH

作为一个懒人程序员，我真的受够了 😤

所以… 我自己写了个开源工具 👇

🔧 **AI Tool Installer**
—— AI编程工具一键安装助手

✨ **它能干什么？**
✅ 自动检测你电脑缺什么（Node、Git 有没有装）
✅ 检测完直接帮你一键补齐
✅ 然后勾选你想装的AI工具
✅ 点一下「安装」就行了！全是自动的 🤯

📦 **目前支持 14 款主流工具：**

📟 终端 CLI 类：
Claude Code · Codex CLI · OpenCode · DeepSeek TUI
Kimi Code · Qoder CLI · OpenClaw · Hermes Agent

🖥️ AI 编辑器类：
Cursor · Windsurf · Trae · Qoder · VS Code

🔄 管理工具：
CC Switch（AI助手统一切换管理）

🌏 **国内用户福音：**
自动检测网络环境，海外源慢就切到 npmmirror.com 镜像
不需要 VPN！不需要配代理！开箱即用！

🆓 **完全开源免费**
MIT 协议，GitHub 上直接可以下载

📥 **获取方式：**
GitHub 搜「questionjie-max/ai-installer」
或者直接去 Releases 下载安装包（macOS / Windows 都有）

安装完打开就是图形界面，点鼠标就能装好所有工具
